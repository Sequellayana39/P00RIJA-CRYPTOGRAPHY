## 🔑 How Security Works (Simple Terms)

- **Your Password is the Key:** The app uses your password to create a unique encryption key. Without it, your data is mathematically impossible to read.
- **Top-Grade Encryption:** We use AES-256-GCM, the same standard used by banks and governments.
- **Strong Key Exchange:** RSA-OAEP-3072 ensures your messages can only be read by the intended recipient.
- **Password Protection:** Argon2id makes sure that even if someone steals your encrypted file, they can't guess your password quickly.
